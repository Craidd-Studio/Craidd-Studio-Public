# Welcome to Craidd Studio

**Open-source · Linux-first · Polyglot IDE · Early Alpha**

Craidd Studio brings multiple projects and languages into one solution while
giving each running application its own IDE window, configuration and debugging
session. The solution declares how projects work together; their installed
ecosystem tools remain responsible for compiling, running and debugging them.

## Current status

The source includes Rust language intelligence, C#/Rust/C++ debugger workflows,
linked windows, the template wizard, native profiling and analysis. Some paths
remain experimental and acceptance is incomplete. The current local package is
an internal debug build, not a qualified public binary release.

Linux is the development target. Arch Linux/GNOME and isolated Xvfb are recorded
test environments; other systems need their own checks. Windows/macOS support
is not promised by this wiki.
